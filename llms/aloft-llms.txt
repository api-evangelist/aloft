# Aloft

> Aloft is the leading FAA-approved provider of drone airspace and fleet-management services in the United States, powering LAANC airspace authorizations, UTM (unmanned traffic management), and enterprise drone operations. The Aloft API V1 exposes airspace advisories, LAANC/Notify & Fly, flights and flight logs, aircraft and battery maintenance, missions, risk assessments, checklists, and map tile layers. Authentication is an http bearer credential (Aloft Token). This llms.txt was generated by API Evangelist from the provider's public OpenAPI and developer surface.

## APIs

- [Aloft API V1](https://api.aloft.ai/v1/docs): 180 operations across 36 resource groups (airspace, flights, aircraft, LAANC/Notify & Fly, missions, risk assessments, maintenance, checklists, files). Base URL https://api.aloft.ai, versioned via /v1.
